# Automated Analysis of Course Evaluation Comments

An NLP-based system that automatically analyzes and categorizes course evaluation comments using machine learning and sentiment classification.

## Overview

Course evaluation comments are usually collected as free-text responses, making them difficult to analyze manually. This project builds an automated pipeline that processes these comments, classifies sentiment, and categorizes feedback — helping educators understand student opinions quickly and efficiently.

## Features

- Text preprocessing and cleaning (tokenization, stopword removal)
- Sentiment classification using Machine Learning models
- Automatic categorization of course evaluation comments
- Interactive Gradio interface for easy user input and results
- Visual summary of analysis results

## Tech Stack

- **Language:** Python
- **NLP:** Natural Language Processing techniques
- **ML:** Machine Learning (sentiment classification)
- **Interface:** Gradio
- **Libraries:** scikit-learn, pandas, nltk (or your actual libraries)
